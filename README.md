# Model Olympics · 模型对决

**两个回答都像是对的？把它们放进同一道题里看。**

选模型时，只读一段流畅的回答，很难判断它有没有完成要求。
Model Olympics 让两条赛道同时回答一道 JSON 映射题，再按相同规则逐项判分。你能展开原始输出，看到哪一项丢了分，以及为什么。

![双赛道结果与原始输出：4/4 和 3/4 的差别可以逐项核对](docs/images/result.png)

### 分数后面，有答案可查

这适合想学习结构化输出评测、或演示模型比较流程的开发者。题目、输出和判定放在同一页，讨论时不用来回切换两个聊天窗口。

第一次打开不用密钥。内置两份人工固定样例：一份全部命中，另一份把密码强度检查映射到了错误函数。**样例的 4/4 与 3/4 用来演示判分，不代表任何真实模型成绩。**

### 在本机打开

准备 **Node.js 24 LTS** 与 npm（也支持 22.12+ 的 22 系列及 26+；不支持 23/25），然后运行：

```sh
git clone https://github.com/shenyangs/model-olympics.git
cd model-olympics
npm run setup
npm run doctor
npm run dev
```

浏览器打开 [http://127.0.0.1:4206](http://127.0.0.1:4206)，终端保持运行；结束时按 Ctrl+C。首次 setup 会联网安装依赖与测试浏览器，下载时间取决于网络。安装问题见 [使用手册](docs/usage.md)。

### 找出那一分丢在哪里

1. 点击 **查看共同提示词**，读一遍邮箱、密码和时间格式化三个需求。
2. 点击 **开始对决**，看两条赛道的逐项检查。
3. **展开原始输出**：样例 B 把 R2 写成 `hashPassword`，而题目要求的是 `validatePassword`。

![运行前的计分板：两条赛道使用同一道题和相同检查规则](docs/images/overview.png)

### 换成你的两个模型

复制 `.env.example` 为 `.env`，填写 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`MODEL_A` 和 `MODEL_B`。重启后选择真实模型模式，即可向同一个 OpenAI 兼容接口的两个模型发送请求。[配置要求](docs/usage.md) 包含支持的参数与超时设置。

每轮发出两次请求，可能收费；失败会直接报错，不会偷偷换成本地样例。真实模型调用尚未实测，已验证的是本地流程与模拟网络测试。

### 这场比赛不决定总冠军

目前只有一道题、一次采样，检查严格 JSON 结构和三个精确映射。它能帮助你读懂这次输出，不能给模型排综合名次。没有历史榜单、多轮统计或代码执行；样例耗时只是文件读取和处理耗时，也不能用来比较模型速度。

### 想继续看代码或验证结果

本地构建、单元测试、浏览器流程和演示录屏已经在 macOS 通过；README 配图来自实际运行的应用。Windows / Linux 实机与全新机器完整安装尚未验证。所有服务仅监听本机，没有部署所需的账号与鉴权，请勿直接暴露到公网。

停止开发服务后，可自行运行：

```sh
npm run build
npm run test
npm run e2e
npm run demo
```
